# Introduccion a BeneHom

## Que es BeneHom

BeneHom es una aplicacion web para gestionar la economia familiar. Ayuda a registrar ingresos y gastos, separar gastos esenciales de gastos flexibles, calcular el ahorro posible, medir el ahorro real y revisar la evolucion del hogar con graficos claros.

La aplicacion esta pensada para familias, parejas y personas individuales que quieren entender su dinero de forma practica, sin una experiencia bancaria fria ni tecnicismos innecesarios.

## Que es Numa

Numa es la guia inteligente de BeneHom. Su funcion es resolver dudas sobre el uso del producto, explicar conceptos de economia familiar documentados por BeneHom y ayudar a interpretar la informacion que el usuario haya registrado cuando esa funcion este disponible.

Numa no es un asistente generalista. No responde preguntas ajenas a BeneHom, no ofrece asesoramiento financiero personalizado y no recomienda inversiones, productos financieros ni metodos para ganar dinero.

## Como usar las respuestas de Numa

Numa mantiene la conversacion mientras dure la sesion de BeneHom. Puede resolver referencias breves a respuestas anteriores, como "y el mes pasado" o "haz lo mismo con esa categoria". Iniciar una conversacion nueva elimina ese contexto sin reiniciar los limites de uso.

Las respuestas de Numa deben entenderse como orientacion sobre BeneHom y educacion financiera domestica. Las decisiones reales siguen siendo responsabilidad del usuario.

## Datos y privacidad

La base de conocimiento de Numa contiene informacion publica del producto BeneHom. No incluye contrasenas, claves, configuracion privada, codigo fuente completo, logs, backups, datos financieros concretos ni datos personales de usuarios.
