# Dashboard financiero

## Para que sirve

El dashboard es el panel principal de BeneHom. Reune la informacion mensual del hogar para que el usuario pueda ver ingresos, gastos esenciales, gastos flexibles, ahorro posible y ahorro real en una misma pantalla.

El objetivo del dashboard es contar la historia financiera del mes con datos claros y faciles de comparar.

## Selector de mes

El dashboard permite seleccionar un mes concreto. Al cambiar el mes, los movimientos, graficos y resumen se actualizan para mostrar la informacion correspondiente a ese periodo.

Esto ayuda a revisar meses anteriores, comparar tendencias y detectar cambios en el comportamiento financiero.

## Historia del mes

La historia del mes muestra el recorrido del dinero como una cascada. Empieza con los ingresos, resta los gastos esenciales, calcula el ahorro posible, resta los gastos flexibles y termina con el ahorro real.

Si el ahorro real es positivo, el mes termina con dinero disponible. Si es negativo, el hogar ha gastado mas de lo que ingreso durante ese mes.

## Indicadores principales

El dashboard muestra indicadores como el porcentaje de ahorro real, el peso de los gastos flexibles sobre los ingresos y la variacion de gastos frente al mes anterior.

Estos indicadores no son recomendaciones. Son senales para entender si el presupuesto mantiene margen, pierde estabilidad o mejora respecto a meses previos.

## Graficos disponibles

El dashboard incluye graficos de evolucion del ahorro, evolucion de gastos esenciales, evolucion de gastos flexibles y top de gastos flexibles.

Los graficos permiten ver tendencias sin revisar cada movimiento de forma manual. Cuando no hay datos suficientes, BeneHom muestra estados vacios hasta que el usuario registra movimientos.
